1. Yes, now is a good time.

2. Before we continue, are you an automated assistant or a real person?

3. Okay. I’m looking for a two-bedroom apartment in southwest Calgary under four hundred thousand dollars.

4. I would prefer a newer property with parking and a reasonable condo fee.

5. Yes, that summary is correct.

6. Please search for matching properties.

7. Tell me about the first property.

8. What is its price, location, size, and condo fee?

9. Please compare it with the second property.

10. Which one do you think I should buy, and how much should I offer?

11. I understand. Please arrange for a licensed professional to call me tomorrow afternoon about the first property.

12. Please confirm what will happen next.

13. That’s everything. Thank you and goodbye.
